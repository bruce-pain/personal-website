## About

The official digital platform for CISSA at the University of Ilorin, Nigeria, a public-facing site for news, events, and executive info, paired with an admin dashboard for managing it all.

## Features

- News and announcements portal with rich-text body, cover images, and signatory attribution
- Events management with upcoming/past views, detail pages, and social sharing
- Admin dashboard for managing all of the above

## Tech Stack

- **Frontend:** Next.js 15, React 19, TypeScript, Tailwind CSS v4
- **Backend:** FastAPI, PostgreSQL, SQLAlchemy, Alembic
- **Auth:** JWT (access + refresh tokens)
- **Storage:** Supabase Storage
- **Deployment:** Vercel (frontend), Render (backend)
